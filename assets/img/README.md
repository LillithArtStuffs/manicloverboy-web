# Image assets

Drop files here with these exact names and the site picks them up automatically —
no code changes needed.

| File | Used for | Suggested size |
| --- | --- | --- |
| `shot-01.png` … `shot-06.png` | Screenshot gallery | 1920×1080 (16:9) |
| `social-card.png` | Link preview on Discord / socials | 1200×630 |

Any slot without a file shows a hatched "SHOT 01" placeholder instead of a broken
image, so the page stays presentable while art is still in progress.

`.jpg` works too — just update the `src` in `index.html` to match the extension.
